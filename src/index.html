Bantuan & FAQ
Pertanyaan tentang Harga & Pembayaran
Paste URL YouTube di kolom sumber video bagian atas, lalu klik "Find highlights →". SEVNT akan mengunduh dan menganalisis video secara otomatis.
Pastikan API Key sudah dimasukkan di Settings dan masih valid. Jika sudah, coba jalankan ulang pipeline dari awal dengan URL atau file yang sama.
API Key disimpan secara lokal di perangkatmu dan tidak dikirim ke server SEVNT. Kamu bisa melihat atau mengubahnya di Settings → API Keys.
Tidak — SEVNT membutuhkan API Key dari penyedia AI (seperti Google Gemini atau Groq) untuk menganalisis konten video dan menemukan highlight secara otomatis.
SEVNT mendukung format MP4, MOV, AVI, MKV, dan WebM. Untuk hasil terbaik, gunakan MP4 dengan codec H.264.
Buka Settings dan pilih opsi "Hapus Cache". Atau buka folder output via tombol "Buka folder" di topbar, lalu hapus folder cache secara manual.
Jumlah perangkat tergantung paket lisensi yang dibeli. Hubungi developer atau cek komunitas Telegram untuk info detail slot perangkat.
Tidak ada versi trial. SEVNT Studio memerlukan lisensi aktif; tanpa lisensi, aplikasi berhenti di layar aktivasi lisensi.

API Keys

🔒 Key dienkripsi di OS keychain (macOS Keychain / Windows DPAPI). Tidak pernah dikirim ke server kami.
⚠ OS keychain tidak tersedia di perangkat ini — key tetap tersimpan lokal di file config (tidak hilang saat kamu tutup/restart app), tapi tidak dienkripsi OS keychain. Tetap tidak pernah dikirim ke server manapun.
Provider ini dipakai untuk SEMUA tahap AI: ringkasan konteks, deteksi potongan/highlight, hook & judul, dan perbaikan caption.
Gratis di Google AI Studio
Gratis di console.groq.com Akun gratis Groq dibatasi ±200.000 token per hari untuk tiap model (pulih bertahap dalam 24 jam). Cukup untuk beberapa video panjang per hari — satu video 1 jam bisa memakai puluhan ribu token. Kalau muncul "rate limit" atau "tokens per day", ganti Model Groq di bawah (tiap model punya jatah sendiri), tunggu beberapa jam, atau upgrade ke Groq Developer.
Cadangan terakhir: dipakai hanya kalau video tidak punya subtitle DAN tidak ada API key yang bisa dibaca. Groq (gratis) tetap didahulukan karena jauh lebih cepat.
Diunduh sekali saat pertama dibutuhkan, bukan saat install. Perkiraan waktu: sekitar 2-5x durasi video di laptop tanpa GPU — pakai Groq (gratis) kalau bisa.
Kalau engine belum siap, kehabisan RAM, atau gagal, transkrip otomatis kembali ke whisper.cpp. Di laptop 8 GB hasil ukur kami: lebih lambat dari whisper.cpp.
